Google Drive Setup Instructions

  1. Create a Media Folder in Google Drive: Create a dedicated folder (e.g., "The Calvary Church - Website Media") and upload high-res photos and videos.
  2. Folder Permission: Set sharing to "Anyone with the link can view" or add church media team email accounts.
  3. Google Cloud Console: Enable the Google Drive API in your Google Cloud Console project and configure OAuth consent.
  4. Manual Fallback: If API keys are not yet configured, you can directly use the Gallery Upload tab to publish images immediately via relative paths or direct image links.
